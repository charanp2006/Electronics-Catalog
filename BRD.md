## 1. Executive Summary

ElectroHub is a full-stack electronics catalog web application that demonstrates NoSQL database usage with MongoDB. The project aims to redesign an existing electronics catalog to showcase document-based data modeling, CRUD operations, and end-to-end integration between frontend, backend API, and MongoDB database.

## 2. Business Objectives

- Demonstrate practical understanding of NoSQL concepts and MongoDB
- Build a full-stack application (frontend + backend + database)
- Showcase CRUD operations, filtering, searching, and sorting
- Compare NoSQL vs SQL design approach
- Create a working, demonstrable project for ABA submission

## 3. Scope

**In Scope:**
- Product catalog with search, filters (brand/category/price), sorting
- Product details with specifications and reviews
- User authentication (signup/login)
- Shopping cart functionality
- Wishlist
- Product comparison
- Basic order placement (demo)
- MongoDB document modeling and data operations

**Out of Scope:**
- Real payment gateway integration
- Inventory management beyond stock tracking
- Admin panel with advanced analytics
- Multi-vendor functionality

## 4. Stakeholders

- Student (Developer)
- Project Guide/Faculty
- Evaluators

## 5. Success Criteria

- Working application with MongoDB backend
- All core features functional
- Clear demonstration of NoSQL usage
- Complete documentation as per requirements

## 6. Assumptions

- MongoDB is installed locally or Atlas cluster is available
- FastAPI and Node.js environments are set up
- Sample data is sufficient for demonstration

- Must use MongoDB as NoSQL database
- Must include frontend, backend, and database
