ElectroHub Admin CMS

Static visual reference for the Admin CMS design. These are non-functional mockups (no backend, no JS logic) — use them to agree on layout, typography and the MongoDB Forest theme before implementation. Each screen below exists in two flavours: Option B (React SPA, sidebar) and Option A (server-rendered, top bar).

Theme tokens: bg #001e2b · panel #062a37 · ink #e8edeb · dim #889397 · phos #00ed64 · alert #ff6960 · fonts JetBrains Mono + VT323.
